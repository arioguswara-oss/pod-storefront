=== POD Simple Checkout ===
Requires at least: 6.5
Requires PHP: 7.4
Stable tag: 0.1.0-dev
Requires Plugins: woocommerce

Kerangka awal plugin WooCommerce untuk POD Storefront.

== Description ==

Versi pengembangan ini hanya menyediakan struktur plugin. Aktivasi tidak
mengubah checkout, cart, order, payment gateway, atau konfigurasi WooCommerce.

== Installation ==

1. Gunakan WordPress lokal atau staging dan aktifkan WooCommerce.
2. Unggah pod-simple-checkout.zip melalui menu Plugin > Tambah Plugin.
3. Aktifkan plugin. Belum ada halaman pengaturan atau fitur checkout.
